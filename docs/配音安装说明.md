# 中文配音（VoxCPM2）安装说明

配音是 0.3.0 新增的**可选**功能：压完字幕后，用 VoxCPM2 按中文字幕逐句合成配音，另外输出 `*_dub.mp4`。字幕版成片照常保留。

VoxCPM2 **不随安装包提供**，需要你自己安装。不用配音的话，可以跳过本文，对其他功能没有任何影响。

## 1. 需要准备什么

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11，64 位 |
| 显卡 | NVIDIA 显卡；配音时显存峰值约 5.7 GB |
| 磁盘 | VoxCPM2 模型约 4.6 GB，另需 Python 环境和 PyTorch 的空间 |
| Python | 单独的 Python 3.10–3.12 环境（VoxCPM 官方要求 Python ≥ 3.10 且 < 3.13） |
| PyTorch | ≥ 2.5.0，CUDA ≥ 12.0（官方要求） |

VoxCPM 必须装在**单独的 Python 环境**里，不要装进本程序自己的环境。本程序通过子进程调用这个环境里的 Python，两边的依赖互不影响。

## 2. 安装步骤

下面以 PowerShell 为例，`<VoxCPM 安装目录>` 换成你自己选的文件夹，路径里最好不要有中文和空格。

### 2.1 新建独立的 Python 环境

```powershell
cd <VoxCPM 安装目录>
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

### 2.2 安装 PyTorch（CUDA 版）

到 PyTorch 官网 <https://pytorch.org/get-started/locally/> 选择 Windows、Pip、和你显卡驱动匹配的 CUDA 版本，复制页面给出的安装命令，在上一步激活的环境里运行。

### 2.3 安装 VoxCPM

```powershell
pip install voxcpm
```

### 2.4 下载 VoxCPM2 模型

模型可以从 Hugging Face 或 ModelScope 下载，二选一。下面用官方 README 里的 ModelScope 写法：

```powershell
pip install modelscope
python -c "from modelscope import snapshot_download; snapshot_download('OpenBMB/VoxCPM2', local_dir='pretrained_models/VoxCPM2')"
```

下载完成后，`<VoxCPM 安装目录>\pretrained_models\VoxCPM2` 里应该有 `config.json` 和模型权重文件。本程序检测时会检查 `config.json`。

## 3. 告诉本程序 VoxCPM 在哪里

有两种方式，任选一种。

**方式一：在程序里填写。** 在配音设置里填写 VoxCPM 环境的 `python.exe` 路径和模型目录。

**方式二：设置环境变量。**

| 环境变量 | 含义 | 示例 |
|---|---|---|
| `YBLOCALIZER_VOXCPM_PYTHON` | VoxCPM 环境里的 python.exe | `<VoxCPM 安装目录>\venv\Scripts\python.exe` |
| `YBLOCALIZER_VOXCPM_MODEL_DIR` | VoxCPM2 模型目录 | `<VoxCPM 安装目录>\pretrained_models\VoxCPM2` |

在 PowerShell 里为当前用户永久设置（设置后需要重新打开本程序）：

```powershell
setx YBLOCALIZER_VOXCPM_PYTHON "<VoxCPM 安装目录>\venv\Scripts\python.exe"
setx YBLOCALIZER_VOXCPM_MODEL_DIR "<VoxCPM 安装目录>\pretrained_models\VoxCPM2"
```

也可以在「系统属性 → 环境变量 → 用户变量」里手动新建这两个变量。

程序里填写的路径优先；没填时使用环境变量。

## 4. 验证

1. 先在命令行确认 VoxCPM 能导入：

   ```powershell
   & "<VoxCPM 安装目录>\venv\Scripts\python.exe" -c "import voxcpm, torch; print('voxcpm ok', torch.cuda.is_available())"
   ```

   输出 `voxcpm ok True` 说明安装正确、能用显卡。

2. 打开本程序，进入「处理」页的「配音」设置。配音开关可以勾选，说明检测通过；如果开关是灰色，下面会显示具体原因和安装提示。
3. 用一条 1–2 分钟的短视频，勾选「生成配音版（*_dub.mp4）」后处理。完成后在字幕页切到「配音版」预览，或在库里点「打开配音版」。

## 5. 常见问题

**配音开关是灰色的？**
看开关下方的原因提示：
- 「未找到 VoxCPM 的 Python」：python.exe 路径不对，注意是 `venv\Scripts\python.exe`；
- 「未找到 VoxCPM 模型目录」：模型目录里没有 `config.json`，可能没下完或目录选错了一层；
- 「VoxCPM 环境中未安装 voxcpm 包」：填的 python.exe 不是装了 voxcpm 的那个环境。

**刚装好 VoxCPM，程序还是检测不到？**
如果是在程序运行中途装好的，请重启程序再看。（0.3.0 是否已改为可重新检测，以发布时为准。）

**用 `setx` 设置了环境变量但没生效？**
`setx` 只对之后新打开的程序生效。关闭本程序后重新打开。

**配音时报显存不足？**
配音时显存峰值约 5.7 GB。请关闭其他占显存的程序（如游戏、其他 AI 工具）。

**配音和画面对不上，或者有的句子被截断？**
配音按字幕时间对齐，每句最多加速到 1.35 倍。配置了 DeepSeek / OpenAI / Ollama 时，超长的句子会先被改写得更短；仍然放不下才会截断。可以先在字幕页把过长的译文改短，再点「重新配音」。

**第一次配音很慢？**
第一次要加载约 4.6 GB 的模型，之后每句的合成时间取决于显卡。Windows 下本程序使用 VoxCPM 的 `optimize=False` 模式加载，速度会比官方标称慢一些，但更稳定。

## 6. 许可、AI 标识与使用提醒

- **许可**：VoxCPM 使用 Apache-2.0 许可证（见下方链接）。
- **配音版是 AI 合成的**：`*_dub.mp4` 里的中文语音由 VoxCPM2 生成。VoxCPM2 模型卡要求标注 AI 生成内容；《人工智能生成合成内容标识办法》也已于 2025 年 9 月 1 日起施行。投稿到 B 站时，建议在创作声明里勾选「使用人工智能合成技术」（具体选项以 B 站投稿页当前显示为准），也可以在简介里注明「配音由 AI 合成」。
- **只使用内置音色**：本程序只用 VoxCPM2 的默认音色合成，不提供声音克隆或参考音频功能。请不要用其他方式让它模仿真实人物的声音。模型卡明确禁止用它冒充他人、诈骗或造谣。
- **视频授权**：发布配音视频前，请确认你拥有原视频的转载或改编授权。
