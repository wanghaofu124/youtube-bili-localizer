# YouTube Bili Localizer 隐私政策

**生效日期：2026-10-14**  
**维护者：wanghaofu124**  
**Microsoft Store 发布者别名：wanghaofu123**  
**支持与隐私问题反馈：** [GitHub Issues](https://github.com/wanghaofu124/youtube-bili-localizer/issues)

## 本机保存的信息

应用会在本机 `%APPDATA%\\YouTubeBiliLocalizer` 保存任务记录、字幕、日志、缓存、模型和用户选择的输出。用户配置的 API 密钥可能保存在该目录的 `.env` 文件中，当前为本地明文配置。用户主动选择的 Cookie 文件路径、Bilibili/Edge/Douyin 持久化浏览器资料也可能保存在本机用户数据目录。请在共享设备上保护、删除或轮换这些内容。

## 网络请求和在线服务

用户主动下载视频、模型或工具时，应用会连接相应来源服务器。用户选择 Cookie 或登录辅助时，请求和凭据可能发送到相应来源平台。用户选择在线翻译或生成式 AI 服务时，字幕、提示词、相关上下文和 API 密钥会发送到用户选择的服务商；第三方的数据处理、留存和收费以该服务商的隐私政策与服务条款为准。

Ollama 只使用本机固定端点 `127.0.0.1:11434`，不提供远程 Ollama 配置。当前版本未内置开发者自营遥测或自动崩溃上传；第三方运行时和依赖的处理规则以其各自政策为准。

用户开始上传视频、封面、标题或其他投稿信息时，相关数据会发送到用户选择的平台；最终公开投稿由用户手动完成。本地 ASR 和本地 OCR 图像处理留在本机；用户选择在线翻译时，OCR 文本可能随相关请求发送到所选服务商。

## 用户控制

用户可删除应用数据目录以清除本机记录；账户、来源平台或 AI 服务商保存的数据需向相应服务商申请删除。应用不出售个人信息。请仅使用自己有权使用的素材和凭据。

如需报告隐私问题或不当、错误的 AI 输出，请使用 [GitHub Issues](https://github.com/wanghaofu124/youtube-bili-localizer/issues/new)。Issue 是公开内容，请勿提交 API Key、Cookie、浏览器配置、日志或字幕原文。

第三方服务的实际规则以其当前政策为准。本政策会随应用实际数据处理方式更新。
