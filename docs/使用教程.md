# YouTube Bili Localizer 详细使用教程

本教程面向第一次使用本项目的用户，按 Windows 环境说明完整流程：安装、配置 API Key、运行 GUI、处理视频、生成中文字幕、辅助发布到 B 站，以及常见问题排查。

> 请只处理你拥有版权、已获得作者明确授权，或许可证允许下载、改编和转载的视频。本工具不会绕过平台登录、验证码、风控、版权检查或最终发布确认。

## 1. 项目能做什么

YouTube Bili Localizer 是一个本地视频本地化工具，可以把授权视频自动处理成带中文字幕的视频，并辅助填写 B 站投稿页面。

主要流程是：

1. 获取素材：从 YouTube 授权链接下载，或导入本地视频。
2. 生成源字幕：用 `faster-whisper` 转写音频，也可以用 OCR 识别画面中的英文字幕。
3. 合并字幕：对同时存在的音频字幕和画面文字做时间线合并。
4. 智能校对：用 DeepSeek 或 OpenAI 修正明显的 ASR/OCR 错误。
5. 翻译中文：生成适合视频硬字幕的中文字幕。
6. 压制视频：用 `ffmpeg` 把 `.srt` 字幕压入视频。
7. 发布辅助：用 Playwright 打开 B 站创作中心，辅助上传视频、填写标题、简介、标签和封面。

## 2. 环境要求

推荐环境：

- Windows 10/11
- Python 3.10 或更高版本
- Git
- ffmpeg
- 网络可访问 YouTube、DeepSeek/OpenAI、B 站
- 可选：NVIDIA 显卡和 CUDA 运行库，用于加速 `faster-whisper`

检查 Python：

```powershell
python --version
```

检查 Git：

```powershell
git --version
```

检查 ffmpeg：

```powershell
ffmpeg -version
```

如果 `ffmpeg` 命令找不到，请安装 ffmpeg 并把 `bin` 目录加入系统 `PATH`。

## 3. 下载和安装项目

克隆仓库：

```powershell
cd D:\codex
git clone https://github.com/wanghaofu124/youtube-bili-localizer.git
cd youtube-bili-localizer
```

创建虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

安装依赖：

```powershell
pip install -r requirements.txt
pip install -e .
playwright install chromium
```

如果 PowerShell 不允许运行激活脚本，可以临时执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## 4. 配置 API Key

复制配置模板：

```powershell
copy .env.example .env
```

用记事本或编辑器打开 `.env`：

```powershell
notepad .env
```

如果使用 DeepSeek：

```env
DEEPSEEK_API_KEY=你的DeepSeek密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_TRANSLATE_MODEL=deepseek-v4-flash
```

如果使用 OpenAI：

```env
OPENAI_API_KEY=你的OpenAI密钥
OPENAI_TRANSLATE_MODEL=gpt-4.1-mini
```

注意：

- `.env` 不会被提交到 GitHub。
- 不要把真实 API Key 发给别人，也不要写进 README、截图或 issue。
- GUI 里也可以临时填写 DeepSeek API Key，程序会用于当前运行流程。

## 5. 可选：配置 CUDA 加速

如果你有 NVIDIA 显卡，可以安装 CUDA 依赖加快转写：

```powershell
pip install nvidia-cuda-runtime-cu12==12.8.90 nvidia-cublas-cu12==12.8.4.1 nvidia-cudnn-cu12==9.8.0.87
```

GUI 中设备选择建议：

- `auto`：推荐，会先尝试 CUDA，失败后自动回退 CPU。
- `cuda`：强制优先用 CUDA，失败后程序也会尝试更安全的配置。
- `cpu`：最稳，但速度慢。

计算类型建议：

- `default`：推荐，程序会按设备选择合适类型。
- `float16`：常用于 CUDA。
- `int8`：常用于 CPU。

## 7. GUI 基础流程

打开 GUI 后，按下面顺序操作。

### 7.1 选择素材

可以选择两种来源：

- YouTube URL：输入视频链接。
- 本地视频：选择电脑上的 `.mp4` 等视频文件。

如果是 YouTube URL，程序可以读取视频总时长，并支持：

- 完整视频
- 指定秒数
- 指定分钟数
- 指定小时数

初次测试建议先处理 10 到 60 秒，确认流程没问题后再跑完整视频。

### 7.2 授权确认

必须勾选授权确认。这个项目只用于合法授权素材。

如果你不确定是否能转载、翻译或二创，不建议处理和发布。

### 7.3 字幕来源选择

推荐选项：

```text
音频 + 画面文字合并
```

各选项说明：

- `自动检测`：优先音频转写，必要时尝试 OCR。
- `音频转写`：只听视频声音生成字幕。
- `画面英文字幕 OCR`：只识别视频画面中的英文字幕，适合无配音但有英文字幕的视频。
- `音频 + 画面文字合并`：同时处理音频和画面文字，适合视频里既有配音又有屏幕字幕、人物介绍、标题条的情况。

如果视频没有配音，只有画面英文字幕，建议用 `画面英文字幕 OCR` 或 `音频 + 画面文字合并`。

### 7.4 Whisper 设置

推荐：

```text
模型：small
设备：auto
计算类型：default
源语言：自动检测
```

模型选择建议：

- `tiny`：最快，但错误较多，只适合快速测试流程。
- `base`：比 tiny 稍准。
- `small`：默认推荐，速度和准确率比较平衡。
- `medium`：更准，但更慢。
- `large-v3`：更准，资源占用也更高。

程序会把视频标题和简介作为提示词提供给 Whisper，帮助识别专有名词，比如人名、赛车型号、品牌、地点等。

### 7.5 翻译设置

翻译器可选：

- `deepseek`：推荐，成本相对低。
- `openai`：需要 OpenAI API Key。
- `none`：只用于流程调试，不适合生成最终中文字幕。

推荐打开智能翻译/智能排版。它会做：

- 结合上下文翻译
- 修正明显 ASR/OCR 错误
- 统一专有名词
- 压缩成适合屏幕显示的字幕
- 避免把时间戳、OCR 标签等内容翻进字幕

### 7.6 字幕样式

常用选项：

- 中文单语：只显示中文字幕。
- 原文在上、中文在下：适合学习或校对。
- 中文在上、原文在下：适合中文观众优先看中文。

字号建议：

- 1080p 视频：20 到 28
- 4K 视频：24 到 36

如果原视频本身底部已有英文字幕，建议把中文字幕位置稍微上移，避免遮挡原字幕。

### 7.7 B 站发布辅助

如果要让程序渲染完后打开 B 站投稿页面，勾选：

```text
渲染完成后打开 B 站创作中心并辅助上传填表
```

浏览器可选：

- Chromium：Playwright 自带浏览器，干净独立。
- Microsoft Edge：更适合使用你常用浏览器环境。

第一次使用时，需要点击登录检查或打开投稿页，手动登录 B 站。登录状态会保存在：

```text
data\bilibili-profile
data\bilibili-edge-profile
```

这些目录不会上传 GitHub。

### 7.8 开始运行

点击“开始全流程”后，程序会依次执行：

1. 准备素材
2. 提取音频
3. 生成源字幕
4. 校对并翻译字幕
5. 压制视频
6. 可选：打开 B 站页面并辅助填写

日志区会显示当前阶段、耗时和关键文件路径。

如果中途想停，可以点击“中断任务”。程序会尽量在当前安全步骤结束后停止。

## 8. 输出目录说明

默认输出在：

```text
outputs\job-日期时间\
```

常见文件：

```text
raw video / *.mp4                  下载或导入的原视频
audio.wav                          提取的音频
audio.srt                          音频转写字幕
ocr.srt                            OCR 识别字幕
source.srt                         最终源字幕
zh.srt                             中文字幕
segments.source.json               源字幕结构化数据
segments.translated.json           翻译字幕结构化数据
publish_metadata.json              自动生成的标题和标签
cover.jpg                          YouTube 封面
rendered.mp4                       压制好字幕的成品视频
bilibili-upload-page.png           B 站投稿页面截图
```

GUI 里的“查看占用并清理”可以：

- 查看所有任务占用空间
- 查看每个任务里的文件
- 删除不满意的成品
- 删除下载源视频
- 删除字幕或中间文件
- 打开任务目录

## 9. B 站发布辅助怎么用

B 站部分不是完全自动提交，而是辅助你完成上传和填表，并在最终提交前停住。

推荐流程：

1. 先点击“登录检查”，确认 B 站账号已登录。
2. 回到 GUI，勾选发布辅助。
3. 跑完整流程。
4. 程序打开投稿页并上传视频。
5. 程序填写标题、简介、标签，并尝试上传封面。
6. 你人工检查页面。
7. 确认无误后，手动点击发布或提交。

简介中可以自动加入原视频链接，建议保留，便于说明授权来源。

如果页面长时间卡在上传或处理阶段：

- 确认网络是否稳定。
- 确认视频文件是否过大。
- 确认 B 站是否要求验证码或重新登录。
- 尝试使用 Edge 浏览器模式。
- 不要在视频还没上传完成时关闭浏览器。

## 10. 直接上传已有成品视频

如果视频已经渲染好了，但 B 站上传失败，不需要重新跑下载、转写和翻译。

在 GUI 的发布区域选择已有成品视频，然后使用发布辅助重新打开投稿页面即可。

这样可以避免因为 B 站网页问题导致整条翻译流程重复运行。

## 11. 命令行完整示例

### 11.1 处理 YouTube 授权视频

```powershell
python -m yblocalizer process `
  --url "https://www.youtube.com/watch?v=VIDEO_ID" `
  --i-have-rights `
  --require-reuse-allowed `
  --max-seconds 60 `
  --subtitle-source merged `
  --whisper-model-size small `
  --device auto `
  --compute-type default `
  --translator deepseek `
  --target-lang zh-Hans
```

### 11.2 使用浏览器 cookies 下载

如果 YouTube 提示登录或 bot 检查：

```powershell
python -m yblocalizer process `
  --url "https://www.youtube.com/watch?v=VIDEO_ID" `
  --i-have-rights `
  --cookies-from-browser chrome `
  --subtitle-source merged `
  --translator deepseek
```

可选浏览器：

```text
chrome
edge
firefox
brave
chromium
```

### 11.3 处理本地视频

```powershell
python -m yblocalizer process `
  --file "D:\video\input.mp4" `
  --i-have-rights `
  --subtitle-source merged `
  --translator deepseek
```

### 11.4 生成双语字幕视频

```powershell
python -m yblocalizer process `
  --file "D:\video\input.mp4" `
  --i-have-rights `
  --translator deepseek `
  --subtitle-mode bilingual-translation-first
```

字幕模式可选：

```text
translated
source
bilingual-source-first
bilingual-translation-first
```

### 11.5 只转写

```powershell
python -m yblocalizer transcribe `
  --video "D:\video\input.mp4" `
  --model-size small `
  --device auto `
  --compute-type default
```

### 11.6 只翻译

```powershell
python -m yblocalizer translate `
  --segments "outputs\job-xxx\segments.source.json" `
  --translator deepseek `
  --target-lang zh-Hans
```

### 11.7 只压制字幕

```powershell
python -m yblocalizer render `
  --video "outputs\job-xxx\raw.mp4" `
  --subtitle "outputs\job-xxx\zh.srt" `
  --font-name "Microsoft YaHei" `
  --font-size 24
```

### 11.8 只打开 B 站发布辅助

```powershell
python -m yblocalizer publish `
  --video "outputs\job-xxx\rendered.mp4" `
  --title "视频标题" `
  --description "已获授权转载/本地化。" `
  --source-url "https://www.youtube.com/watch?v=VIDEO_ID" `
  --tags "中文字幕,授权转载,视频翻译" `
  --browser edge
```

## 12. 常见问题

### 12.1 GUI 打开时弹出终端怎么办

使用：

```powershell
.\launch_gui.vbs
```

调试时才使用：

```powershell
.\launch_gui_debug.bat
```

### 12.2 YouTube 链接无法下载

可能原因：

- 视频需要登录。
- YouTube 要求 bot 验证。
- 视频地区不可用。
- 视频不允许下载或复用。
- 链接不是标准视频页。

可尝试：

```powershell
--cookies-from-browser chrome
```

或在 GUI 里选择浏览器 cookies。

### 12.3 字幕翻译错误很多

优先检查源字幕是否已经错了。

建议：

- Whisper 模型至少用 `small`。
- 设备用 `auto`。
- 字幕来源用 `音频 + 画面文字合并`。
- 打开智能翻译。
- 对专业内容，尽量保留 YouTube 标题和简介，因为它们会作为上下文帮助识别专有名词。

### 12.4 视频里只有英文字幕，没有配音

选择：

```text
画面英文字幕 OCR
```

或：

```text
音频 + 画面文字合并
```

OCR 识别效果和画面清晰度、字幕大小、字幕位置、背景复杂度有关。

### 12.5 B 站页面一直加载

可能原因：

- 未登录或登录过期。
- B 站页面改版。
- 需要验证码。
- 上传还在处理。
- 使用的浏览器 profile 被后台进程占用。

可尝试：

- 点击“关闭后台 B 站浏览器”。
- 换成 Edge。
- 手动打开 B 站创作中心确认能正常访问。
- 使用较小视频测试。

### 12.6 点了关闭后台，为什么还占用

浏览器可能有多个子进程，或者 Edge/Chromium 正在被其他窗口使用。请确认：

- 关闭的是程序专用资料目录对应的浏览器进程。
- 没有其他上传页面仍在运行。
- 任务已经停止，不在等待上传或处理。

### 12.7 CUDA 报错

先用：

```text
设备=auto
计算类型=default
```

程序会自动从 CUDA 回退到 CPU。如果仍报错，先用 CPU 跑通流程，再检查 CUDA 依赖版本。

### 12.8 不想重新跑全流程，只想重新上传

使用 GUI 中的已有成品视频发布功能，或命令行：

```powershell
python -m yblocalizer publish --video "outputs\job-xxx\rendered.mp4" --title "标题"
```

## 13. 推荐测试流程

第一次使用建议这样测：

1. 准备一个你确定有授权的短视频。
2. 只处理前 10 秒。
3. 翻译器选 `deepseek`。
4. 字幕来源选 `音频 + 画面文字合并`。
5. 关闭 B 站发布辅助。
6. 跑完后打开 `rendered.mp4` 检查字幕。
7. 确认字幕没问题后，再打开 B 站发布辅助测试上传。
8. 最后再处理完整视频。

这样可以减少长视频重复转写、翻译和压制的时间。

## 14. 发布前检查清单

发布到 B 站前建议人工确认：

- 视频确实有授权。
- 标题没有误导或夸大。
- 简介包含原视频链接和授权说明。
- 标签与内容相关。
- 封面合适。
- 中文字幕没有明显误译。
- 原视频中的人物、品牌、地点、数字没有翻错。
- 没有遮挡重要画面或原字幕。
- B 站页面没有提示版权、格式或审核风险。

## 15. GitHub 安全说明

项目已经默认忽略：

```text
.env
data/
outputs/
videos/
demo/**/*.mp4
demo/**/*.wav
*.egg-info/
__pycache__/
```

不要提交：

- API Key
- 浏览器 profile
- 登录 cookies
- B 站账号资料
- 未授权原视频
- 生成后的成品视频
- 大型中间文件
