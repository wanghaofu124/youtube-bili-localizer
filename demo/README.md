# Public demo assets

`authorized-demo-10s.mp4` is the short, authorized input used by the local
demo and benchmark commands. Only this input and files generated from it may
be committed under `demo/artifacts/`.

The committed artifacts are `source.srt`, `zh.srt`, `rendered.mp4`, and a
single preview frame (`preview.png`) generated from the rendered video.

Do not add browser screenshots, cookies, profile data, API responses, or media
whose redistribution rights are unclear. Larger diagnostic runs belong in the
ignored `outputs/` directory.
