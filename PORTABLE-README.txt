YouTube Bili Localizer v0.3.2 portable package

1. Extract this ZIP to a folder where your Windows account can write files.
2. Start YouTubeBiliLocalizer.exe from the extracted folder.
3. If Windows shows a SmartScreen or other security check, verify the SHA-256 value from the GitHub release before deciding whether to run it. This unsigned package does not remove Windows security checks.
4. The desktop window needs Microsoft WebView2. The default audio workflow needs FFmpeg/ffprobe and the selected Whisper model; open the app's dependency center to check and install components when needed.

Runtime data is stored under %APPDATA%\YouTubeBiliLocalizer, separately from this extracted folder.
